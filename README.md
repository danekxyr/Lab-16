# Лабораторная работа № 16

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Линейный и двоичный поиск

## Назначение файлов проекта

* **`main.c`** — реализация линейного поиска `linear(const int a[], int n, int key)` и двоичного поиска `binary(const int a[], int n, int key)` в отсортированном по возрастанию массиве, возвращающих индекс элемента или `-1` при отсутствии.
* **`self.c`** — реализация функций `count_key(const int a[], int n, int key)` (подсчёт числа вхождений) и `first_key(const int a[], int n, int key)` (поиск первого индекса) линейным проходом в неотсортированном массиве.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов с подробной трассировкой переменных для первого примера.

## Ограничения и правила

* Для корректной работы функции `binary` передаваемый массив обязан быть отсортирован по возрастанию; середина вычисляется без переполнения через `left + (right - left) / 2`.
* Для линейного поиска (`linear`, `count_key`, `first_key`) сортировка массива не требуется.
* При пустом диапазоне (`n = 0`) функции поиска возвращают `-1`, а `count_key` возвращает `0`.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab16
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```

## Пример работы

### Основная программа (`main.c`)
Массив: `{-4, -1, 2, 6, 9}`, поиск `key = 2` и `key = 3`:
```text
2: 2 2
3: -1 -1
```

### Самостоятельная работа (`self.c`)
Массив: `{2, 7, 2, -1, 2}`:
```text
key=2 -> Количество 3; индекс 0
key=7 -> Количество 1; индекс 1
key=9 -> Количество 0; индекс -1
n=0, key=2 -> Количество 0; индекс -1
```
