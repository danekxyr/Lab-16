Тест 1 (исходная программа, key = 2 и key = 3 в массиве {-4, -1, 2, 6, 9}):

Ожидаемый результат:
2: 2 2
3: -1 -1
Фактический результат:
2: 2 2
3: -1 -1
Статус: совпало

Трассировка переменных для Теста 1 (массив a = {-4, -1, 2, 6, 9}, n = 5):
1. Итерация цикла main: key = 2 (условие 2 <= 3 истинно).
2. Вызов linear(a, 5, 2):
   - i = 0: a[0] = -4 != 2
   - i = 1: a[1] = -1 != 2
   - i = 2: a[2] = 2 == 2 -> ранний выход, возврат индекса 2.
3. Вызов binary(a, 5, 2):
   - Начало: left = 0, right = 4.
   - Шаг 1 (0 <= 4): mid = 0 + (4 - 0) / 2 = 2. Проверка a[2] == 2 (2 == 2) -> ранний выход, возврат индекса 2.
   - Вывод: "2: 2 2".
4. Итерация цикла main: key = 3 (условие 3 <= 3 истинно).
5. Вызов linear(a, 5, 3): перебирает индексы i = 0..4 (-4, -1, 2, 6, 9), совпадений нет -> после цикла возврат -1.
6. Вызов binary(a, 5, 3):
   - Начало: left = 0, right = 4.
   - Шаг 1 (0 <= 4): mid = 0 + (4 - 0) / 2 = 2; a[2] = 2 < 3 -> left становится mid + 1 = 3 (right = 4).
   - Шаг 2 (3 <= 4): mid = 3 + (4 - 3) / 2 = 3; a[3] = 6 > 3 -> right становится mid - 1 = 2 (left = 3).
   - Шаг 3: условие left <= right (3 <= 2) ложно, границы пересеклись -> цикл завершается, возврат -1.
   - Вывод: "3: -1 -1".
7. Итерация цикла main: key = 4 (условие 4 <= 3 ложно) -> завершение программы.
